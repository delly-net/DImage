# 任务计划重新生成

此技能用于对 EAZY.RAG 知识库当前项目「小D图像」（项目 ID: 3）中已存在执行计划的任务，按固定工作流重新生成 MD 格式执行计划，并以新版本保存（版本号递增，不覆盖旧版本）。本技能仅生成与保存执行计划并展示，不执行任务。

## 使用方法

```
/eazy-rag-task-replan {任务Id}
```

任务 ID 由参数 `{任务Id}` 提供或从上下文识别；未提供且无法识别时，按「模块确认」步骤读取当前模块下非已归档任务列表供用户选择。

## 功能

1. **模块确认与确定目标任务 ID**：使用 `/eazy-rag-module-get` 获取当前工作模块名称；若未设置（无值），先运行 `/eazy-rag-module-set` 设置当前工作模块。任务 ID 由参数或上下文识别；若无法识别，调用 `mcp__eazy-rag__list_tasks`（moduleId=当前模块Id）读取当前模块下**所有非已归档任务**列表，经 AskUser 询问用户选择目标任务。
2. **读取任务最新执行计划、所有执行历史结果与补充说明**：
   - 调用 `mcp__eazy-rag__get_task`（taskId）→ 任务名称/描述/状态/当前功能设计版本号，校验任务归属当前项目且未归档；
   - 调用 `mcp__eazy-rag__get_execution_plan`（taskId，默认最新版本）→ 最新执行计划正文 + 执行结果 + 该版本补充说明；
   - 调用 `mcp__eazy-rag__list_execution_plan_versions`（taskId）→ 所有版本的元信息与补充说明（**不含执行计划正文**）。
3. **提取新的补充关键词**：基于任务描述、最新执行计划、执行结果与本次重新生成的新要求，提取/联想**新的补充关键词**（新增功能点、领域词、技术词等），用于后续检索。
4. **搜索关联已归档任务**：调用 `mcp__eazy-rag__search_archived_tasks`（projectId=3，keywords=关键词）搜索关联已归档任务信息，作为参考。
5. **关键词工具搜索本地文件**：直接使用关键词工具（Grep/Glob）搜索本地项目文件，寻找可复用实现与既有模式。
6. **分析思考**：结合任务现状（既有执行计划/历史执行结果/补充说明）与搜集到的信息，识别关键设计决策、与既有计划的差异点及不确定点。
7. **AskUser 提问**：对无法确定的信息向用户提问——**所有问题都必须提供备选项**（AskUserQuestion 带 options）；提问时调用 `mcp__eazy-rag__add_task_question`（taskId，question，options JSON 数组）将问题实时存储到任务问答子表；用户回答后调用 `mcp__eazy-rag__answer_task_question`（taskId，questionId，answer）记录回答；所有提问经操作日志在**执行历史**中展示。
8. **生成 MD 格式执行计划**：结合所有信息重新生成执行计划，包含章节：任务描述/任务分析/执行步骤/执行输出/结果验收/参考文档/执行规范/注意事项；**须包含完整的原有执行计划内容**，并在原有基础上用**【新增】【修改】【移除】**文字标签标明相对既有版本的差异（保留适用内容，更新变更部分）。
9. **保存为新版本执行计划**：调用 `mcp__eazy-rag__save_execution_plan`（taskId，content，forceNewVersion=true）——**始终创建新版本**（版本号递增），不覆盖既有版本，完整保留版本历史；有可参考的已归档/历史任务时传入 relatedTaskIds（关联历史任务 Id 的 JSON 数组）。
10. **展示与分享**：**不再向用户展示执行计划完整正文**，改为输出「执行计划概要」——概要含：任务名称、本次新版本号、新版本各章节标题清单、以及相对上一版本的**【新增】【修改】【移除】**变更点摘要（每条一行，总计 ≤ 10 条）；随后**用分享码拼接完整分享查阅 URL**：`https://rag.jueyun.net/share/{分享码}`（前端访问地址已由系统配置「系统外部网址」在技能下载时填充），以 Markdown 超链接 `[分享查阅]({完整URL})` 输出；**仅展示，不执行**（不调用 `mcp__eazy-rag__confirm_execution`）。

## 注意事项

- 所有 MCP 调用必须携带正确的项目 ID：3。
- **所有步骤非注明需要询问或确认时，无需询问和确认，直接执行**。
- **目标任务必须属于当前项目且未归档**：调用 `mcp__eazy-rag__get_task` 校验任务归属；已归档任务不允许重新生成。
- **先确定任务 ID 再操作**：任务 ID 由参数/上下文提供；无法识别时须读取模块下**非已归档任务**列表供用户选择，禁止猜测任务 ID。
- **提问必须提供备选项**：所有 AskUserQuestion 问题均须带 options，禁止无选项提问。
- **问答实时入库 + 执行历史展示**：提问 → `add_task_question`；用户回答 → `answer_task_question`；两者均实时写操作日志（Feature=taskPlanQa），管理员可在操作日志界面查看全部提问。
- **保存必须为新版本**：调用 `save_execution_plan` 时须传 `forceNewVersion=true`，确保每次创建新版本（版本号递增），不覆盖既有版本。
- **新版本须包含完整原文并标注差异**：重新生成的新版本执行计划须**保留完整原有执行计划内容**，并在原有基础上用**【新增】【修改】【移除】**文字标签标明相对既有版本的差异（补充说明⑥）。
- **分享查阅链接**：**不再向用户展示执行计划完整正文**，改为输出「执行计划概要」，保存新版本执行计划后务必从 `save_execution_plan` 返回中获取分享码（shareCode），用它拼接分享查阅 URL `https://rag.jueyun.net/share/{分享码}` 并以超链接输出，供用户在浏览器查看执行计划（前端访问地址已由系统配置「系统外部网址」在技能下载时填充）。
- 生成的执行计划必须包含 任务描述/任务分析/执行步骤/执行输出/结果验收/参考文档/执行规范/注意事项 全部章节。
- **仅展示，不执行**：本技能只负责生成与保存执行计划，不执行任务、不调用 `confirm_execution`；执行由用户确认后另行处理。
